This website is not aimed at children, and we do not knowingly collect data from anyone under 16 through it. We only show a minor's name or photo with the written consent of a parent or guardian.

We keep personal data in password-protected accounts that only the people running Freaks 3x3 can access, and we only share it as described above.

If we change how we use personal data, for example by adding analytics, we will update this page and the date above first.
